# 이커머스 멀티모달 EDA와 RFM 고객 세분화

주문 한 건에 담긴 수치, 범주, 날짜, 상품명, 이미지 배열을 한 파이프라인에서 처리하고, 고객을 RFM으로 나눠 실행 가능한 전략을 제안한다. 분석 로직은 `DataAnalyzer` 클래스에 두고, 탐색 과정과 차트는 노트북에 둔다.

## 프로젝트 개요

- 분석 단위는 주문 행이고, RFM 단위는 고객이다.
- 이미지 특징은 행마다 반복문을 돌리지 않고 NumPy 배열의 축 축소로 평균과 표준편차를 구한다.
- 결측 평점은 카테고리별 평균으로 채운다.
- 수량 IQR 이상치만 울타리로 캡핑한 뒤 `amount = quantity * unit_price`로 금액을 다시 맞춘다. 주문 행은 지우지 않아 구매 빈도가 유지된다.
- Recency 기준일은 인자로 주지 않으면 데이터의 최종 거래일이다.

## 데이터 설명

| 항목 | 값 |
| --- | --- |
| 파일 | `data/ecommerce_orders.csv` |
| 규모 | 주문 3,999건, 컬럼 13개, 고객 640명, 상품 48개 |
| 기간 | 2024-03-01 ~ 2025-06-30 (486일) |
| 출처 | 이 저장소의 `scripts/generate_data.py`가 고정 시드로 생성한 합성 데이터 |
| 라이선스 | MIT |

공개 상품 사진을 쓰지 않았다. 이미지는 카테고리별 밝기 패턴을 가진 16×16 배열이고, CSV `image_flat` 열에 공백으로 구분한 소수 문자열로 저장했다. 세그먼트 정답 라벨은 파일에 넣지 않았다. 같은 시드로 스크립트를 다시 실행하면 같은 CSV가 나온다.

데이터 유형은 다섯 가지다.

| 유형 | 컬럼 |
| --- | --- |
| 수치 | `quantity`, `unit_price`, `amount`, `rating` |
| 범주 | `category`, `region`, `channel` |
| 날짜 | `order_date` |
| 텍스트 | `product_name` |
| 이미지 배열 | `image_flat` (16×16, 분석 시 8×8로 다운샘플) |

RFM에 필요한 `customer_id`, `order_date`, `amount`가 있다. `amount`는 `quantity * unit_price`다.

파생 컬럼은 `image_mean`, `image_std`, `name_length`, `name_word_count`다.

## 세그먼트 요약

기준일은 2025-06-30이다. 점수는 5분위이고, Recency는 경과일수가 작을수록 높은 점수다. 처리 후 총매출은 378,678,500원이다.

| 세그먼트 | 고객 수 | 고객 비중 | 평균 최근성(일) | 평균 구매 횟수 | 평균 누적 구매액(원) | 매출 비중 | 특징 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| VIP | 113 | 17.7% | 10.1 | 14.45 | 1,893,968 | 56.5% | 최근 구매, 높은 빈도, 높은 금액 |
| Loyal | 153 | 23.9% | 38.9 | 8.13 | 548,774 | 22.2% | 고객 비중과 매출 비중이 비슷한 반복 구매 |
| New | 110 | 17.2% | 9.9 | 1.00 | 53,682 | 1.6% | 최근 첫 구매, 빈도 1회 |
| At Risk | 95 | 14.8% | 124.2 | 7.03 | 589,677 | 14.8% | 누적 금액은 Loyal과 비슷하고 마지막 구매는 오래됨 |
| Churned | 141 | 22.0% | 272.2 | 1.79 | 107,549 | 4.0% | 오래전 마지막 구매, 매출 기여는 작음 |
| Regular | 28 | 4.4% | 156.1 | 3.29 | 128,893 | 1.0% | 위 규칙에 남지 않은 중간 고객 |

규칙(1~5점, 먼저 일치한 규칙이 우선):

- VIP: R, F, M 모두 4 이상
- Loyal: R, F, M 모두 3 이상
- New: R이 4 이상이고 F가 2 이하
- At Risk: R이 2 이하이고 F, M이 3 이상
- Churned: R, F 모두 2 이하
- Regular: 남은 고객

## 비즈니스 인사이트

### 인사이트 1. VIP 매출 집중

(근거) VIP 113명은 전체 640명의 17.7%이고, 처리 후 총매출 378,678,500원의 56.5%인 214,018,400원을 만든다. 1인당 평균 구매는 14.45회이고 마지막 구매의 중앙값은 11일이다. VIP 매출 가운데 Electronics 72,655,850원과 Fashion 72,578,500원을 더하면 145,234,350원으로, VIP 매출의 67.9%다.

(실행) VIP 113명에게 Electronics와 Fashion 신상품 48시간 선공개, 무료 반품, 전용 상담을 묶은 멤버십을 제안한다. 기대 효과는 매출의 56.5%를 만드는 최근 11일 구매 주기를 유지하는 것이다.

(검증) 이 비중은 486일 관찰 창의 누적 매출이라, 멤버십이 이탈을 늦추는지는 혜택 사용 로그와 가입 전후의 구매 간격이 있어야 확인할 수 있다.

### 인사이트 2. At Risk를 Churned보다 먼저 되돌리기

(근거) At Risk 95명(14.8%)의 평균 누적 구매액은 589,677원으로 Loyal 548,774원과 가깝고, 마지막 구매 중앙값은 121일(사분위 103~136일)이다. 매출 기여는 56,019,300원(14.8%)이다. Churned 141명(22.0%)의 마지막 구매 중앙값은 275일이고 매출 기여는 15,164,350원(4.0%)이다.

(실행) At Risk 95명에게 마지막 구매 카테고리 상품의 7일 한정 재구매 쿠폰을 보낸다. 기대 효과는 매출 기여가 4.0%인 Churned보다, Loyal과 비슷한 누적 금액을 가진 At Risk가 더 멀어지기 전에 재구매를 만드는 것이다.

(검증) 121일의 공백이 가격 불만인지 원래의 구매 주기인지는 이 거래 데이터만으로 가릴 수 없고, 쿠폰 실험의 대조군 반응이 없으면 할인 효과가 맞는지 반증할 수 없다.

### 인사이트 3. 최근 1회 구매 고객의 두 번째 주문

(근거) New 110명(17.2%)은 구매 횟수가 모두 1회이고 평균 구매액은 53,682원이다. 매출 기여는 5,905,050원(1.6%)이고, 마지막 구매 중앙값은 9일이다.

(실행) New 110명에게 첫 구매일로부터 14일 안에 쓸 수 있는 2차 구매 쿠폰을 첫 주문 카테고리의 연관 상품에 걸어 보낸다. 기대 효과는 빈도 1회 고객을 Loyal(평균 8.13회, 평균 누적 548,774원) 쪽으로 옮겨 이 세그먼트의 매출 기여를 키우는 것이다.

(검증) 1회 구매가 선물처럼 의도된 단건인지 알려면 가입일과 유입 경로가 더 필요하고, 14일 쿠폰 이후에도 재구매가 없으면 가격 혜택이 원인이 아니라는 반증이 된다.

### 인사이트 4. Fashion·Electronics 매출과 Food 평점

(근거) 처리 후 Fashion 매출 119,302,250원(31.5%)과 Electronics 114,208,950원(30.2%)을 합하면 전체의 61.7%다. Fashion 평균 주문액은 157,807원이고 Food는 30,609원이다. Food 평점 평균은 3.40으로 여섯 카테고리 중 가장 낮고, 평점 결측률은 22.8%(119/521)로 가장 높다. Beauty 평점 평균은 4.49다.

(실행) Food를 구매한 고객에게 리뷰 요청을 먼저 보내고, 평점 3.40 구간 상품의 구성과 품질을 점검한다. 기대 효과는 매출 비중은 4.2%로 작지만 평점과 리뷰 공백이 가장 큰 카테고리의 신뢰 신호를 메우는 것이다. 매출 확대의 진열 우선순위는 Fashion과 Electronics에 둔다.

(검증) 평점 결측이 불만족 고객의 무응답인지 리뷰 화면 미노출인지는 리뷰 노출 로그가 있어야 구분되고, 카테고리 평균 대치는 집단 평균을 유지할 뿐 결측 원인을 설명하지 못한다.

## 실행 방법

Python 3.8 이상. 분석 라이브러리는 NumPy, Pandas, Matplotlib, Seaborn만 사용한다.

```bash
cd A1-1-TASK
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m src.pipeline
```

`python -m src.pipeline`은 로드, 이미지·텍스트 피처, 카테고리 평균 대치, IQR 탐지, 수량 캡핑, 금액 재계산, RFM 요약까지 출력한다.

노트북을 연다.

```bash
jupyter notebook notebooks/analysis_report.ipynb
```

노트북은 첫 셀에서 `MPL_IGNORE_SYSTEM_FONTS=1`을 설정한 뒤 Matplotlib를 불러온다. macOS에서 시스템 폰트 목록 파싱이 실패하는 환경에서도 차트가 그려지고, 한글 제목은 AppleGothic 파일이 있으면 그 글꼴로 표시한다.

데이터를 같은 시드로 다시 만들려면 `python scripts/generate_data.py`를 실행한다.
